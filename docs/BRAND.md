# Stovia brand assets

The owner-approved logo is `apps/web/public/brand/stovia-logo.png`. It is the exact supplied raster artwork, preserved without redrawing or changing its colors. The header, footer, launch preview fallback, browser icon, Apple touch icon and social metadata all use this asset.

`apps/web/app/brand-mark.tsx` is the shared UI component. Keep new brand placements tied to this component and the same asset. Token-specific tickers and user-uploaded token images are separate token identities.

The matching X header is `apps/web/public/brand/stovia-x-header.png`. These assets were created using the built-in image-generation tool, then selected by the owner. Prompt briefs: geometric navy S monogram with burnt-orange upper-right terminal on warm ivory; matching editorial X header with “The stock-backed token launchpad.” and “Building on Robinhood Chain.” No green.
